# Practical 10 – OSSP

## Experiment 1: Inodes, Hard Links and Symbolic Links

* Investigate inode numbers and file metadata.
* Create and test hard links.
* Create and test symbolic links.
* Demonstrate broken symbolic links.

## Experiment 2: File I/O using mmap() and read()/write()

* Implement file I/O using memory mapping.
* Implement file I/O using read() and write().
* Compare the two methods using a large test file.

## Files

* `mmap_file.c` – Memory-mapped file I/O demonstration
* `read_write_file.c` – File I/O using read() and write()
* `mmap_benchmark.c` – Large-file mmap benchmark
* `read_benchmark.c` – Large-file read benchmark
* `data.txt` – Input file for the file I/O demonstration
